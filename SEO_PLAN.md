# International SEO Plan & Keyword/Page Map

All keyword targets below are **hypotheses** to validate with search-volume tools per market. No rankings are promised.

## Implemented foundations
- Locale-prefixed URLs `/en /tr /fr /ar /de /ja /nl /sv /es`, pre-rendered HTML.
- Unique localised `<title>` and meta description per page; one H1; semantic sections.
- `rel=canonical` + `hreflang` for all 9 locales + `x-default` on every page; `sitemap.xml` with `xhtml:link` alternates.
- JSON-LD: Organization (name, url only — factual) and BreadcrumbList. Product schema deliberately omitted until product data is verified.
- Descriptive, translated alt text; responsive AVIF/WebP/JPEG; lazy loading; width/height to prevent layout shift.
- Demo: `noindex,nofollow`. Production: build with `DEMO=0 SITE_URL=…` to enable indexing and sitemap in robots.txt.

## Six resource/article briefs (no fake case studies)
1. **Planning space for source-separation collection rooms** — audience: architects, developers. Cover early design decisions, coordination with collection operators, accessibility.
2. **Which waste streams should your building separate?** — household, packaging, glass, batteries, used oil; link to configuration switcher.
3. **New build vs retrofit installation** — coordination steps, surveys, constraints; CTA: discuss an installation.
4. **Procurement checklist for building waste-separation systems** — tender questions (documentation, maintenance, warranty, references) for municipal buyers.
5. **Running a feasibility study or pilot** — scope, stakeholders, evaluation criteria.
6. **Technical integration with building services** — electrical, access, maintenance; CTA: technical briefing.
